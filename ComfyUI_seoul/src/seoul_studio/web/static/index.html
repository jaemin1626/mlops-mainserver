      작업으로 보내기

      선택한 영상을 작업 폴더로 보내거나 브라우저에 비식별화본을 보관합니다.

      동작
      대상
      형식

      Frame 추출

      영상마다 동일한 이름의 폴더를 만들고, 그 안에 N 프레임마다 1장씩 추출합니다.

      사용 방법 · Frame 추출

      추출 간격(N)을 입력하면 0, N, 2N… 프레임에서 JPG를 저장합니다. 예: 30이면 약 1초에 1장(30fps 기준).

      처음 사용할 때 체크리스트
      • Detector는 이미지만 보낼 수 있습니다.
      • VLM은 이미지 또는 영상을 선택할 수 있습니다.
      • 이미지는 generate/<저장 폴더명>/<영상명>/ 에 저장됩니다.

      저장 위치: vlm/generate/<폴더명>/<영상명>/

      비식별화

      Detector 프레임 추출·영상 보내기·보관 시 블러 처리합니다. 이미 Anony/에 비식별화본이 있으면 우선 사용합니다.

      하나 이상 선택하세요.
