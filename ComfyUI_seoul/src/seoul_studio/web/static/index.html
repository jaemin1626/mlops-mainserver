    generate_datasets

      작업으로 보내기

      선택한 영상을 YOLO 또는 VLM 작업 폴더로 보냅니다.

      대상
      형식

      Frame 추출

      영상마다 동일한 이름의 폴더를 만들고, 그 안에 N 프레임마다 1장씩 추출합니다.

      사용 방법 · Frame 추출

      추출 간격(N)을 입력하면 0, N, 2N… 프레임에서 JPG를 저장합니다. 예: 30이면 약 1초에 1장(30fps 기준).

      처음 사용할 때 체크리스트
      • YOLO는 이미지만 보낼 수 있습니다.
      • VLM은 이미지 또는 영상을 선택할 수 있습니다.
      • 이미지는 generated/영상이름/ 폴더에 저장됩니다.

      저장 위치: detector/generated

      생성 불가

      GPU가 학습에 활용 중이므로, 학습이 완료된 후에 생성을 해주시길 바랍니다.
