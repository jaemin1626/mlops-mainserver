📁 Detector 데이터

상위 폴더를 체크하면 하위 데이터를 포함합니다. 부분 체크는 일부 파일만 선택된 상태입니다.

선택한 폴더
실제 사용 파일 목록 · 개별 제외
노드 추가는 위에서 선택한 Dataset version과 branch를 부모로 연결합니다. 새 Dataset version 생성은 version과 첫 branch 이름을 직접 지정합니다. 노드 추가는 선택한 version 아래에 새 branch 이름으로 연결합니다. 생성에 실패하면 학습을 시작하지 않습니다.


루트 바로 아래 폴더만 표시됩니다. 폴더를 선택하면 내부 하위 폴더까지 모두 포함됩니다.










두 버튼 모두 선택한 폴더와 클래스를 반영합니다. 기존 YOLO 라벨을 사용해 train.txt, test.txt와 data.yaml을 생성합니다. 학습 90% / 검증·테스트 10%로 나누며 객체 박스를 새로 생성하지는 않습니다.
